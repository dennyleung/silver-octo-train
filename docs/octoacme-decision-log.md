# OctoAcme Decision Log Template

Use this template to record key project decisions, their rationale, owners, and impacts. A decision log prevents decisions from being revisited unnecessarily, supports onboarding, and provides an audit trail.

---

## How to Use

1. Log any decision that has a material impact on scope, schedule, budget, quality, or approach.
2. Include the context that led to the decision, alternatives considered, and the rationale for the chosen option.
3. Assign a **Decision Owner** — the person accountable for the decision (maps to the Accountable role in the RACI).
4. Record who was consulted and informed.
5. Review the log at retrospectives and update the Status column if a decision is superseded.

## Decision Entry Template

Copy the block below for each new decision:

---

### Decision #[N]: [Short Title]

**Date:** YYYY-MM-DD
**Decision Owner:** [Name / Role]

**Context:**
Briefly describe the situation that required a decision to be made.

**Decision:**
State clearly what was decided.

**Rationale:**
Explain why this option was chosen.

**Alternatives Considered:**
- Option A: [Description] — [Why not chosen]
- Option B: [Description] — [Why not chosen]

**Consulted:** [Names / Roles]
**Informed:** [Names / Roles]

**Impact:**
Describe the effect on scope, schedule, budget, quality, or team structure.

**Status:** Open / Superseded by Decision #[N] / Closed

## Decision Owner by Decision Type

| Decision Type | Default Decision Owner | Escalate To |
|---|---|---|
| Sprint scope (add/remove stories) | Product Owner | Product Manager |
| Budget change | Project Sponsor | Executive leadership |
| Release date change | Project Manager | Project Sponsor |
| Technical approach | Developer lead (with team) | Project Manager |
| Quality gate criteria | Quality Lead | Project Manager |
| Backlog priority | Product Owner | Product Manager / Project Sponsor |
| Team structure / resourcing | Project Manager | Project Sponsor |
