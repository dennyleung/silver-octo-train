# OctoAcme RACI Template

Use this template to assign ownership for project activities. For each activity, assign one or more roles using the RACI codes below.

**RACI Codes:**
- **R** — Responsible: Does the work to complete the activity.
- **A** — Accountable: Owns the outcome; approves the work (only one per row).
- **C** — Consulted: Provides input; two-way communication.
- **I** — Informed: Kept up to date; one-way communication.

---

## How to Use

1. Copy this template into your project folder or a project-specific doc.
2. Add or remove rows to match your project's activities.
3. Add or remove columns to reflect your team's specific roles.
4. Ensure every row has exactly **one A** (Accountable) owner.
5. Review the completed RACI with the team during kickoff to confirm agreement.
